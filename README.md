# MotionAI — منصة الموشن جرافيك (مجانية)

تحويل تسجيل صوتي إلى فيديو موشن جرافيك طولي (1080×1920) بخمسة ستايلات، **بدون Claude API وبدون بطاقة دفع**.

## كيف تعمل
1. **قص الصمت** (`engine/auto_cut.py` + جسر `engine/audio_pipeline.py`): يحذف الصمت ≥ 250ms ويُبقي نفَساً طبيعياً، ثم يُفرَّغ الصوت **بعد القص** فتتطابق الكلمات مع الصوت النهائي.
1. **التفريغ بالدارجة** (`engine/transcriber.py`): **بدون أي مفتاح أو بطاقة**: Google ar-DZ (للدارجة الجزائرية) ثم Whisper المحلي (نموذج small، يُنزَّل تلقائياً أول مرة ~460MB) + قاموس تصحيح الدارجة. مفاتيح Groq/Gemini اختيارية تماماً. بديل أخير: لصق النص يدوياً.
2. **مخطط بقواعد** (بدون ذكاء اصطناعي) يقسم الكلام إلى مشاهد ويختار الكلمة المميّزة.
3. **محرك رسم Python (Pillow)** يرسم كل إطار، ويُرمَّز على مراحل (15 ث) بـ ffmpeg ثم يُدمج مع الصوت.

## النشر (Streamlit Community Cloud)
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub (الملف `app.py` في الجذر).
2. على share.streamlit.io: New app ← اختر المستودع ← الملف `app.py`.
3. (اختياري) Settings ← Secrets: `GROQ_API_KEY = "gsk_..."` (وللدقة الأعلى اختيارياً `GEMINI_API_KEY`) ليستعمله الجميع، (إلزامي: المفتاح لم يعد يُطلب من المستخدم).

## مفتاح Groq المجاني
console.groq.com ← إنشاء حساب بالبريد ← API Keys ← Create. الحد المجاني حوالي 20 طلباً/دقيقة و2000/يوم، وحجم الملف حتى 25MB (يُضغط تلقائياً).

## الخطوط
تُحمَّل تلقائياً من Google Fonts عند أول تشغيل. للأمان ضع هذه الملفات في مجلد `fonts/`:
`Anton-Regular.ttf`, `ArchivoBlack-Regular.ttf`, `PinyonScript-Regular.ttf`, `Tajawal-Black.ttf`
(من fonts.google.com). عند غيابها يُستعمل خط DejaVu وتكون النتيجة أقل جمالاً.

## ملاحظات مهمة
- موارد Streamlit المجانية محدودة (حوالي 0.078–2 نواة و690MB–2.7GB رام)، فالتصيير بطيء. إن ضاق بك الحال جرّب 720p/24fps، أو انقل المشروع إلى Hugging Face Spaces (يتطلب Dockerfile).
- الصور ثلاثية الأبعاد والأشخاص المقصوصون في الفيديوهات المرجعية لا يمكن توليدها برمجياً؛ المنصة تقلّد الحركة والألوان والخطوط، وتقبل صورة خلفية وصورة شخصية اختيارية.
